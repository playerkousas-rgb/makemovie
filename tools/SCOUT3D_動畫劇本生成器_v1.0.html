⚡ 方法 A：直接貼落 CMD 即刻出片（完全唔使放劇本上 Git！）

1. 只要你部電腦已經 git pull 咗一次 Git 入面嘅 SCOUT 3D 3D 元件庫。
2. 喺下面用 AI 或手動執好分鏡對白 ➔ 撳橙色制「📋 複製 CMD 一鍵直出指令（連劇本）」。
3. 打開電腦 makemovie 資料夾嘅 CMD 貼上 Enter —— 劇本已自動編碼喺指令入面，零開檔、零 Git 上傳直接產出 output/集數.mp4！

📁 方法 B：放劇本上 Git 留底／方便秒速改字幕

1. 撳綠色制「💾 下載 .py 劇本檔」放入 makemovie\episodes\（或者勾選 --write-py 貼落 CMD 自動寫入檔案）。
2. 想改對白只需打開個 .py 改最頂頭第 1 行嘅 SUBTITLE_LINES，行 --fast-sub-only 1.5 秒即換好字幕！
3. 複製埋下面產出嘅 git add / commit / push 指令，一貼就推埋上 GitHub 備份。
